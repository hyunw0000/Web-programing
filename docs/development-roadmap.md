# 개발 과정 로드맵

## 1단계: 데이터 수집 (Data Engineering)

### 수집 대상

- 국내 유가: 오피넷 API (주유소 가격, 지역 평균)
- 국제 유가/환율: yfinance 또는 Alpha Vantage
- 뉴스: 네이버 뉴스 API (유가/석유/중동 정세 키워드)
- 현물시장/공장도가: 정유사 공지/협회 자료 크롤링

### 산출물

- 소스별 수집 스크립트
- 수집 주기 스케줄러 (시간/일 단위)
- 표준화된 원천 데이터 테이블

## 2단계: AI 모델링 및 분석

### 예측 모델

- 베이스라인: ARIMA 또는 Prophet
- 고도화: LSTM (충분한 데이터 확보 후)

### LLM 활용

- 뉴스 감성 점수화: 상승/하락 요인 분류
- 시장 브리핑 생성: 수치 + 뉴스 요약 결합

### 산출물

- 예측 모델 학습/추론 파이프라인
- 모델 성능 리포트 (MAE, RMSE, MAPE)
- AI 브리핑 템플릿 및 품질 점검 기준

## 3단계: 백엔드 개발 (Server & DB)

### 권장

- Django + Django REST Framework
- PostgreSQL (확장 시 TimescaleDB)
- 비동기 작업: Celery + Redis

### 주요 도메인

- 가격 데이터 관리
- 예측 결과 관리
- AI 브리핑 관리
- 사용자/알림 관리

## 4단계: 프론트엔드 개발 (UI)

### 핵심 화면

- 실시간 지표판
- 미래 예측 차트
- AI 시장 브리핑
- 지역별 경쟁 주유소 현황

### 권장 기술

- React 또는 Next.js
- Chart.js 또는 Highcharts

## 5단계: 테스트 및 검증

- 단위 테스트: 계산, 변환, 프롬프트 생성 로직
- 통합 테스트: 외부 API -> 내부 DB 데이터 플로우 검증
- 성능 테스트: 대용량 시계열 조회/시각화 응답속도
- AI 출력 검증: 샘플링 기반 포맷/정합성 점검

## 6단계: 배포 및 운영

- CI/CD: GitHub Actions (필요 시 Jenkins 확장)
- 모니터링: API 실패율, 지연시간, 예측 오차 추적
- 운영 정책: API 장애 시 캐시/직전값 fallback 전략
