# 고웹 팀플 제안서 - 유가 예측 사이트 제작

## 1) 개발 동기 (Motivation)

**"직관과 운에 맡기던 유류 구매를 데이터 기반의 과학적 의사결정으로 전환"**

- 정보의 파편화/과부하: 운영자는 국제유가, 환율, 공장도가, 현물가, 뉴스 등을 분산된 채널에서 매일 확인해야 함
- 구매 타이밍의 민감도: 하루 차이로도 리터당 손익이 크게 달라져 월 손익에 큰 영향 발생
- DX 격차: 대기업은 예측 시스템 보유, 개인 주유소는 경험 의존도가 높아 의사결정 리스크가 큼

## 2) 프로그램의 필요성 (Necessity)

### 2.1 구매 원가 절감 및 마진 극대화

- 변동 추이 예측 기반 저점 매수, 고점 판매 전략 지원
- 리터당 소폭 절감도 누적 시 월 단위 유의미한 순이익 개선 가능

### 2.2 시간 절약 및 업무 효율화 (One-Stop Dashboard)

- 오피넷, 금융 데이터, 뉴스를 단일 화면으로 통합
- 운영자의 정보 탐색 비용과 수작업 분석 시간을 대폭 절감

### 2.3 AI 기반 정성 데이터 분석

- 뉴스/이슈를 상승/하락 요인으로 분류해 직관적 인사이트 제공
- 전문가 리포트 수준의 시장 브리핑 자동 생성

### 2.4 재고 관리 리스크 최소화

- 가격 하락 구간 고가 재고 보유 리스크(재고 평가손실) 완화
- 구매 시점 최적화로 운영 안정성 확보

## 3) 결론 및 비전 (Conclusion)

**"개인 주유소를 위한 맞춤형 AI 에너지 컨설턴트"**

본 서비스는 단순 조회 사이트가 아니라,  
`언제/어디서/얼마에 구매할지`에 대한 근거 중심 의사결정을 지원하는 B2B SaaS 플랫폼이다.

### 상용화 확장 모델

1. 구독형 모델: 실시간 예측/알림 제공
2. 현물 중개/광고: 대리점-주유소 연결 수수료 및 광고
3. 에너지 데이터 판매: 유통 트렌드 데이터 상품화
