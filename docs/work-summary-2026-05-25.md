# 작업 요약 - 2026-05-25

## 개요

유가 예측 의사결정 지원 대시보드의 기존 기능을 점검하고, 이미 백엔드에 구현되어 있던 알림 관련 API를 프론트엔드 화면에 연결했습니다. 주요 개선 방향은 알림 규칙을 단순 등록/삭제하는 수준에서, 실제 운영자가 규칙 상태를 관리하고 즉시 평가 결과와 이력을 확인할 수 있도록 만드는 것이었습니다.

## 적용한 개선 사항

### 1. 알림 규칙 활성/비활성 토글

- 등록된 알림 규칙 목록에서 각 규칙의 상태를 바로 변경할 수 있도록 `활성/비활성` 토글 버튼을 추가했습니다.
- 기존 백엔드 `PATCH /api/v1/alerts/rules/<rule_id>` API를 사용합니다.
- 상태 변경 후 대시보드 데이터를 다시 불러와 화면과 서버 상태가 맞도록 처리했습니다.

### 2. 알림 즉시 평가 기능

- 등록된 알림 규칙 카드에 `즉시 평가` 버튼을 추가했습니다.
- 기존 백엔드 `POST /api/v1/alerts/evaluate` API를 사용합니다.
- 평가 완료 후 발생한 알림 기록 수를 사용자 메시지로 표시합니다.
- 평가 중에는 버튼 문구를 `평가 중`으로 바꾸고 비활성화해 중복 클릭을 줄였습니다.

### 3. 최근 알림 이력 표시

- 대시보드 하단에 `최근 알림 이력` 섹션을 추가했습니다.
- 기존 백엔드 `GET /api/v1/alerts/history` API를 사용합니다.
- 표시 항목:
  - 발생 시각
  - 규칙 이름
  - 현재가
  - 예측가
  - 알림 메시지

### 4. 알림 처리 메시지 개선

- 알림 등록, 삭제, 상태 변경, 즉시 평가 결과를 같은 메시지 영역에서 표시하도록 정리했습니다.
- 성공/실패 메시지의 스타일이 상황에 맞게 적용되도록 판별 로직을 보강했습니다.

### 5. UI 스타일 보강

- `즉시 평가` 버튼, 상태 토글 버튼, 테이블 액션 영역 스타일을 추가했습니다.
- 기존 카드/테이블 디자인과 맞도록 색상과 크기를 조정했습니다.
- 모바일 화면에서도 알림 폼과 테이블이 깨지지 않도록 기존 반응형 구조를 유지했습니다.

## 현재 기능 흐름

1. 대시보드가 실시간 지표, 7일 예측, AI 시장 브리핑, 구매 점수를 불러옵니다.
2. 사용자가 알림 규칙을 등록합니다.
3. 등록된 규칙을 활성/비활성으로 전환할 수 있습니다.
4. `즉시 평가` 버튼으로 현재 데이터와 예측 데이터를 기준으로 알림 조건을 평가합니다.
5. 조건을 만족한 알림은 최근 알림 이력에 기록되고 화면에서 확인할 수 있습니다.

## 추가 개선 제안

### 1. 알림 중복 기록 방지

현재는 같은 조건이 반복 평가되면 같은 규칙으로 여러 알림 이력이 생길 수 있습니다. 운영 환경에서는 규칙별 쿨다운 시간 또는 동일 예측일 기준 중복 방지 로직을 두는 것이 좋습니다.

### 2. 알림 이력 필터

최근 알림 이력이 많아지면 다음 필터가 필요합니다.

- 규칙별 필터
- 상승/하락 유형 필터
- 기간 필터
- 활성 규칙만 보기

### 3. 알림 방식 확장

현재 알림은 DB 이력에만 기록됩니다. 실제 서비스에서는 다음 채널로 확장할 수 있습니다.

- 이메일
- 카카오 알림톡
- Slack/Discord 웹훅
- 관리자 페이지 배지

### 4. 예측 신뢰도 표시 강화

현재 하한/상한과 뉴스 보정 예측이 표시됩니다. 다음 정보를 추가하면 의사결정 품질이 좋아집니다.

- 최근 예측 오차율
- 모델별 신뢰도
- 뉴스 보정 전후 차이율
- 데이터 최신성 표시

### 5. 운영용 설정 분리

현재 로컬 개발 기준으로 실행되고 있습니다. 배포 전에 다음 구성이 필요합니다.

- 운영 DB 분리
- API 키 보안 관리
- `DEBUG=False` 운영 설정
- CORS 허용 도메인 제한
- 정기 수집/예측 스케줄러 운영 방식 확정
